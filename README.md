# 🏦 NovaBank – Full Stack Banking System

A modern full-stack banking web application with authentication, transactions, and dashboard UI.

## 🚀 Features
- 🔐 Account creation & login
- 💰 Deposit / Withdraw / Transfer
- 📊 Dashboard with analytics
- 📋 Transaction history
- 👤 Profile management

## 🛠 Tech Stack
- Backend: Python (HTTP Server)
- Frontend: HTML, CSS, JavaScript
- Storage: JSON

## ▶️ Run Locally
```bash
python server.py
